# pb_article_flask_app

This is a microblog application developed using Flask framework.

To start application:
First on terminal go to project folder.
Run command : python -m flask run

This will invoke development server on port 5000. It will provide you link: http://127.0.0.1:5000   (Ctrl + click) the link and the application will start on browser.

Application will let you Type blog article and save into database.
